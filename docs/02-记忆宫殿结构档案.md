## 六、踩坑记录（今晚实证）

| # | 坑 | 解法 |
|---|---|---|
| 1 | **两个库**：之前 recall 只查 SQLite → 98% 记忆搜不到 | 三通道都要查 |
| 2 | **HNSW 92% 缺失** → 向量检索被禁用 | `repair --mode from-sqlite`（需先停 MCP）|
| 3 | **mempalace daemon 起不来**：`another writer owns local backend 'chroma'` | MCP 已占 writer 位，**不能**再起 daemon |
| 4 | **`LIMIT ?` 占位符报错**（sqlite3 URI 模式 "uses 1 supplied 2"）| 改字面量 `LIMIT 5` |
| 5 | **补丁里用未定义变量**（NL）→ NameError 被 except 吞 | 落盘前 py_compile + 独立测试 |
| 6 | **bash heredoc 多层转义**吃反斜杠 | 一律用 `chr(10)` / `chr(92)` |
| 7 | **Git Bash 的 /tmp = 系统 Temp** → 污染 WorkBuddy 更新目录 | 临时文件写 `LOG_DIR/` |
| 8 | **定时任务重启会掉** + schtasks ONLOGON 要管理员 | HKCU Run 键 + 常驻进程 |
| 9 | **系统 Python 的 psutil 反复被更新搞坏**（3 次）| 统一用 `pythonw（见 config.py）` |
| 10 | **无窗口启动**：wscript 是 LOLBin 被安全拦 | Python `creationflags=0x08000000`（CREATE_NO_WINDOW）|
